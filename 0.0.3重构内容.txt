## v0.03 重构更新选项完整清单

### 一、整体框架

| 编号 | 更新项 | 说明 |
|:---:|:---|:---|
| 1.1 | 移动端社交应用风格布局 | 参考 PADDOCKCLUB / OWLPOST，单列垂直滚动，卡片式模块，PC 端最大宽度 480px 居中，移动端全宽 |
| 1.2 | 魔法世界视觉主题 | 深羊皮纸底色 #2b1e10，卡片半透明深色 rgba(0,0,0,0.5)，暗金边框 #c9a96e，标题用 MedievalSharp 或 IM Fell English 字体 |
| 1.3 | 顶部状态栏 | 左侧当前游戏时间（日期+时段），右侧玩家头像+在线绿点 |
| 1.4 | 标题栏 | 居中显示模板名（如 OWLPOST），魔法手写体风格 |
| 1.5 | 底部导航栏 | 固定底部，4 个标签图标+文字，等宽分布 |
| 1.6 | 页面切换逻辑 | 点击标签切换视图，不刷新页面，单页应用模式 |
| 1.7 | 底部版本号 | 导航栏上方小字：「魔法法典版本 · 测试 v0.03」 |

### 二、右上角公告栏

| 编号 | 更新项 | 说明 |
|:---:|:---|:---|
| 2.1 | 公告按钮 | 固定在页面右上角（position: fixed），图标为📜卷轴，z-index: 999，不随页面切换消失 |
| 2.2 | 公告面板 | 点击按钮展开/关闭，卡片式弹窗，魔法世界风格（深色羊皮纸底+金边） |
| 2.3 | 面板内容 | 当前版本号、已修复 Bug 列表（可填“暂无”）、已知问题列表、下次更新预告（v0.04 内容） |
| 2.4 | 关闭方式 | 面板右上角 × 按钮关闭；点击面板外区域关闭 |
| 2.5 | 数据源 | 公告内容以 JS 对象/数组存储，方便后续修改 |
| 2.6 | 响应式 | 移动端面板宽度适配，不超出屏幕 |

### 三、「闲聊」标签（💬）

| 编号 | 更新项 | 说明 |
|:---:|:---|:---|
| 3.1 | 好友头像横滑栏 | 顶部横向滚动，所有固定好友头像+名字+在线状态小圆点 |
| 3.2 | 地图入口 | 横滑栏最左侧固定「🗺️ 地图」入口，点击切换为地图模式 |
| 3.3 | 聊天区域 | 对话气泡形式展示消息，好友回复靠左灰色底，玩家消息靠右绿色/金色底 |
| 3.4 | 输入框+发送按钮 | 底部固定，输入文字点发送或回车发送 |
| 3.5 | 聊天选项按钮 | API 返回选项时，在好友回复气泡下方生成 2~3 个选项按钮（垂直排列），点击即选中发送 |
| 3.6 | 选项忽略逻辑 | 玩家若直接打字而忽略选项，选项消失，继续自由对话 |
| 3.7 | 选项后果处理 | 选择后调用 API 生成后果，更新友好度、日历事件、剧情状态、可能触发新事件 |
| 3.8 | 场所地图模式 | 点击地图入口后，聊天区切换为静态 ASCII 地图，所有地点节点为可点击按钮 |
| 3.9 | 场所进入触发 | 点击地点 → 系统消息“你来到了 [地点]” → API 生成场景描述 + 2~3 个场所行动选项 |
| 3.10 | 场所内好友偶遇 | 若该地点有在线好友，自动出现在场所选项里，点击切换到与 TA 对话 |
| 3.11 | 群聊/组队事件卡片 | 触发组队事件时横滑栏生成临时群聊卡片，点击进入多人场景对话 |
| 3.12 | 对话历史持久化 | 切换好友或标签后再切回，保留最近 N 条对话记录（暂存内存） |

### 四、「日历」标签（📅）

| 编号 | 更新项 | 说明 |
|:---:|:---|:---|
| 4.1 | 顶部时间大字显示 | 当前日期（如 10月3日·星期三）和时段（上午/下午/晚上），醒目展示 |
| 4.2 | 周历网格视图 | 7 列（周一到周日），当天高亮金边，有事件的日期显示彩色圆点 |
| 4.3 | 事件圆点颜色 | 🔴魁地奇 🟢课程 🟡好友生日 🔵特殊事件 |
| 4.4 | 今日日程卡片 | 列出当前时段安排（课程/事件/空闲），若有事件显示「前往」按钮 |
| 4.5 | 前往跳转 | 点击「前往」→ 切换到闲聊标签并自动加载对应场所/好友对话 |
| 4.6 | 即将到来事件列表 | 未来 3 天内事件按时间排列，可点击查看详情 |
| 4.7 | 手动推进按钮 | 底部「⏳ 推进时段」按钮，点击推进一个时段并触发 API 事件生成 |
| 4.8 | 日历自动更新 | 闲聊标签中的事件触发、场所移动自动更新日历标记 |
| 4.9 | 生日提醒 | 好友生日当天日历显示🎂标记，闲聊中可能触发生日事件 |
