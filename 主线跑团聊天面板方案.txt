主线跑团聊天面板方案

一、定位

在当前霍格沃茨模拟器网页内新增一个「主线剧情 / 跑团对话」页面。
它不是普通客服聊天，也不是纯论坛消息，而是用于推进主线剧情的沉浸式跑团面板。

核心用途：
1. 玩家通过输入行动或选择快捷行动推进剧情。
2. 系统生成旁白、NPC 对话、场景变化和判定结果。
3. 保留剧情记录、任务状态、线索、背包和角色状态。
4. 后续可与 Owl Ping 的 owl chat、猫头鹰邮局、个人档案、金库、对角巷等模块联动。

建议路由：
/app/story-chat

建议入口：
1. 左侧导航新增「主线剧情」。
2. Owl Ping 桌面内的 owl chat 可跳转到该页面。
3. 后续也可以在每日新闻或猫头鹰邮局中加入剧情触发入口。

二、整体体验

整体感觉：
网页内的魔法跑团控制台。

视觉方向：
1. 羊皮纸日志。
2. 魔法通信面板。
3. Owl Ping 聊天 App。
4. 掷骰结果以金色印章或魔法符文形式出现。

不要做成现代客服聊天窗口。
应更像「霍格沃茨主线冒险记录 + 玩家行动输入器」。

三、页面布局

推荐三栏布局：

左侧：剧情状态栏
中间：主对话区
右侧：角色卡与物品栏

移动端可折叠为：
1. 顶部显示章节和地点。
2. 中间显示对话。
3. 底部输入行动。
4. 状态栏和背包通过抽屉打开。

四、左侧剧情状态栏

内容包括：
1. 当前章节
2. 当前地点
3. 当前任务目标
4. 当前时间线
5. 重要 NPC
6. 已获得线索
7. 当前危险等级
8. 学院声望
9. 主线分支标记

示例：
当前章节：第一章：迟到的猫头鹰
当前地点：霍格沃茨城堡外庭
任务目标：找到寄错的入学通知书
重要 NPC：麦格教授、陌生的黑袍学生
线索：带有银色蜡封的信件、被烧焦的羽毛

五、中间主对话区

消息类型：
1. 系统旁白
2. NPC 发言
3. 玩家行动
4. 掷骰判定
5. 获得线索
6. 获得物品
7. 任务更新
8. 章节转场

消息展示建议：
1. 系统旁白使用羊皮纸正文样式。
2. NPC 发言带头像、姓名、身份标签。
3. 玩家行动右侧展示，像行动记录。
4. 掷骰结果用独立小卡片：
   - 检定类型
   - 骰子结果
   - 属性修正
   - 最终结果
   - 成功 / 失败 / 大成功 / 大失败
5. 任务更新用金色边框提示。
6. 获得物品可带小图标。

六、底部输入区

输入方式：
1. 自由文本输入行动。
2. 快捷行动按钮。
3. 选择式剧情选项。

自由输入示例：
我检查信封上的蜡封。
我询问麦格教授是否还有其他学生收到类似信件。
我尝试用荧光闪烁照亮走廊。

快捷行动按钮：
1. 观察环境
2. 询问 NPC
3. 使用物品
4. 检查线索
5. 继续前进
6. 暂时休息
7. 施放魔咒
8. 进行判定

七、右侧角色卡与物品栏

角色卡内容：
1. 姓名
2. 学院
3. 年级
4. 血统
5. 魔杖
6. 守护神
7. 当前状态

属性建议：
1. 魔咒
2. 魔药
3. 草药
4. 黑魔法防御
5. 飞行
6. 变形术
7. 魔法史
8. 洞察
9. 魅力
10. 勇气

物品栏内容：
1. 魔杖
2. 金加隆 / 银西可 / 铜纳特
3. 入学通知书
4. 地图
5. 魔药
6. 任务道具
7. 线索碎片

八、跑团判定机制

基础判定：
1d20 + 属性修正 >= 难度 DC

难度参考：
1. DC 8：简单
2. DC 12：普通
3. DC 15：困难
4. DC 18：危险
5. DC 22：极难

结果分级：
1. 大成功：自然 20 或最终值高于 DC 10 点以上
2. 成功：最终值 >= DC
3. 失败：最终值 < DC
4. 大失败：自然 1 或最终值低于 DC 10 点以上

示例：
检定：洞察
骰子：14
属性修正：+2
最终：16
难度：15
结果：成功

九、剧情推进方式

第一版推荐使用前端固定剧情节点。
不要一开始就接复杂 AI，先把 UI 和流程做稳。

节点结构建议：
1. nodeId
2. title
3. sceneText
4. npcMessages
5. choices
6. requiredChecks
7. rewards
8. nextNodeId

选择项结构：
1. id
2. text
3. type
4. checkAttribute
5. dc
6. successNodeId
7. failureNodeId

十、存档方式

第一版：
1. 聊天记录存 localStorage。
2. 当前章节、节点、线索、物品也存 localStorage。
3. 支持清空剧情重新开始。

第二版：
1. 后端新增 story save。
2. 与用户账号绑定。
3. 可保存多条剧情线。
4. 支持章节回放。

十一、与现有模块联动

个人档案：
读取玩家姓名、学院、年级、血统、魔杖、守护神。

巫师银行 / 金库：
剧情奖励可增加金加隆、银西可、铜纳特。
某些剧情选择可消耗货币。

对角巷商店：
剧情中获得购物清单。
购买物品后可在跑团中使用。

每日新闻：
主线推进后可生成新闻摘要。

猫头鹰邮局：
NPC 可通过猫头鹰发送任务信件。

Owl Ping：
owl chat 作为主线跑团入口。
嗅嗅钱包跳巫师银行。
猫头鹰档案跳个人档案。
Owl Shop 跳对角巷商城。

1. 新增页面：

   /app/story-chat

   - 三栏布局

5. 第一版内置章节：
   第一章：迟到的猫头鹰

6. 第一版内置 NPC：
   - 麦格教授
   - 猫头鹰邮差
   - 黑袍学生

   - 银色蜡封
   - 被烧焦的羽毛

十三、第二版升级清单

1. 接入后端存档。
2. 加入 AI 旁白和 NPC 对话生成。
3. 加入多章节剧情。
4. 加入角色属性成长。
5. 加入任务奖励和经济系统。
6. 加入 NPC 好感。
7. 加入学院声望。
8. 加入主线分支。
9. 加入失败代价。
10. 加入剧情回顾。

十四、UI 细节建议

颜色：
1. 背景使用深棕、暗红、羊皮纸色组合。
2. 文字必须保证清晰，不要使用低对比金色小字。
3. 重要结果使用金色，但正文用深墨色或米白。

字体：
1. 标题可用复古或魔法感字体。
2. 正文优先保证可读。
3. 骰子和数值可用 8-bit 或复古游戏感字体。

动效：
1. 系统旁白可打字机出现。
2. 掷骰卡片可短暂翻转或发光。
3. 获得线索时出现印章动画。
4. 章节切换时使用羊皮纸翻页效果。

十五、最终目标

把主线跑团聊天面板做成霍格沃茨模拟器的剧情核心。
它负责把个人档案、金库、商店、每日新闻、邮局、Owl Ping 等模块串成一条可以持续推进的主线冒险。
